# python-guest-manager
A beginner Python console application for managing an event guest list.

## Features

- View all guests
- Filter confirmed guests
- Filter pending guests
- Search for guests
- Add guests
- Remove guests
- Confirm guests
- Cancel guests
- View guest statistics
- Validate user input

## Concepts Practiced

- Variables
- Lists
- Parallel lists
- Loops
- Nested loops
- Conditionals
- Input validation
- Indexing
- List modification
- Program state
- String methods
- Basic statistics

## What I Learned

This project helped me understand how indexes work when modifying lists, especially when multiple pieces of information need to stay synchronized.

## Current Limitations

This project intentionally uses parallel lists as a learning exercise. A future version will replace this structure with dictionaries and eventually functions.
